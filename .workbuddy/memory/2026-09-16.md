   - 高见远（架构师）→ `docs/02-架构设计.md` + `openapi.yaml` + `ADR-001~003`：**25 个异常码**、逐列回填权限表、双键幂等设计、9 路径 / 9 操作 / 27 schema。

3. **我做的跨文档一致性检查与裁决**（关键动作）
   - 查出架构文档自相矛盾：§2.5 断言"抖加批次应零 P0"，但 §4.1 把 `CROSS_SOURCE_TOTAL_MISMATCH` 定为 P0 阻断且举例正是抖加 700 vs 表内 400。**裁决降为 P1 不阻断**——理由：账号表「抖加」列无批次/日期维度，该等式无法验证，阻断会常态化（表内累计必然大于单日声明额），阈值退化为噪声。
   - 收紧 `CROSS_SOURCE_FIELD_CONFLICT` 适用条件为"同一博主同一字段值不同"；物料里"文本爆火音乐 vs 表内高高=李老师"不满足，改归 P1 `CROSS_SOURCE_SCOPE_MISMATCH`。
   - 要求补 `EXC-xx ↔ 异常码 enum` 对照表，作为 Spec / OpenAPI / 测试三处统一锚点。

4. **Phase 1.5 汇编 Spec v1.0** → `docs/Spec-v1.0.md`（13 章节 + 附录 A/B）
