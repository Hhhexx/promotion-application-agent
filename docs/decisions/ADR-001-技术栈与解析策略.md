# ADR-001：技术栈与解析策略（规则为主 + LLM 可选交叉校验）

## Status

Accepted（Phase 1）

## Background

题目要求实现「推广申请处理 Agent」，交付可运行演示 + 代码仓库 + 简短说明，并明确「可以使用单 Agent、多 Agent 或普通工作流，请简单说明选择原因」。用户已确认三项关键决策：交付形态为 Web 演示应用（单页操作台）、解析策略为「规则解析为主 + LLM 可选交叉校验」、技术栈为「Python + FastAPI + 轻前端」。

本 ADR 记录**技术栈**与**解析策略**两项选型，理由与风险。选型基线来自 `references/architecture/mvp-stack.md`（后端 FastAPI、AI 应用栈）与 `references/cost-models/development-costs.md`。

## Decision

### 1. 技术栈：Python + FastAPI + 轻前端（静态单页，无构建步骤）

| 层 | 选型 | 理由 |
|---|---|---|
| 后端框架 | FastAPI（Pydantic v2） | MVP 速度高；Pydantic 天然承载数据契约（见 ADR-002 与 `openapi.yaml`）；自动生成 OpenAPI，前后端契约同源 |
| 数据契约 | Pydantic v2 `BaseModel` | 请求/响应/领域模型一套类型，跨层不传裸 dict |
| Excel 读写 | openpyxl | 纯 Python、离线、无外部服务；满足「写测试副本」需求 |
| 前端 | 原生 HTML/CSS/JS 单页（无构建） | 演示态无需工程化；离线可跑；面试可当场打开 |
| 图标 | Lucide（锁定唯一，见架构文档 §7） | 16/20/24px 规范，离线本地化 |
| 测试 | pytest | 规则/归一化/交叉校验/缺门均需单测 |

**否决项：** 不引入前端构建工具链、不引入数据库、不引入容器编排——演示态无必要，均为过度设计。

### 2. 解析策略：规则解析为主 + LLM 作为可选交叉校验

- 规则解析为**唯一主干**：正则/模式匹配产出结构化 `LineItem` 与 `ClaimSummary`，全程确定性、可单测、离线可跑。
- LLM 为**可选旁路**（接入点见架构文档 §5.4）：仅在「规则未命中的低置信行」与「语义交叉校验」处使用；**不一致即升级人工（P0）**，绝不替代规则。
- 无密钥时 `llm_adapter` 降级为 no-op，核心功能**不降级**。

## 校验分级（异常定档原则）

解析与校验产出异常后需定档 P0（阻断）/ P1（警告）/ P2（提示）。定档不是"越严越好"，而是有明确边界：

**P0 阻断只允许三类问题：**

1. **正确性缺陷**：同一数据源内部矛盾且可确定性判定（`TOTAL_MISMATCH`、`COUNT_MISMATCH`、`DATE_ORDER_INVALID`）。
2. **需求未满足**：必填字段缺失或写入目标无法确定（`FIELD_MISSING`、`UNPARSED_LINE`、`MATCH_AMBIGUOUS`、`MATCH_NOT_FOUND`）。
3. **契约安全 / 数据完整性破坏**：会污染表或破坏幂等（`DUPLICATE_WITHIN_REQUEST`、同博主同字段冲突 `CROSS_SOURCE_FIELD_CONFLICT`、`LLM_RULE_CONFLICT`）。

**跨源校验的定档（本 ADR 显式记录，供答辩）：**

- `CROSS_SOURCE_TOTAL_MISMATCH` **定为 P1（不阻断）**。理由：账号表「抖加」列**无批次/日期维度**，无法证明"表内累计 400"与"文本单日 700"属同一批次，等式不可验证；若据此阻断，则表内累计必然大于单日声明额，每批正常申请都将永远无法落表——阻断常态化即阈值失效。降级后仍**禁止自动调和**，只标注口径待人工确认。
- `CROSS_SOURCE_FIELD_CONFLICT` **保持 P0，但适用条件收紧**为"**同一博主、同一字段、文本值与表内已填值不同**"。物料「文本支付人=爆火音乐 vs 表内高高=李老师」不满足（高高不在本批明细内），归 `CROSS_SOURCE_SCOPE_MISMATCH`（P1）。

详见架构文档 `docs/02-架构设计.md` §4.5；定档结果登记于 `docs/decisions/OPEN-DECISIONS.md` 关闭记录。

## Consequences

### 正面
- 可复现、可解释、离线可跑、可测试，全面满足「不猜测」硬约束。
- FastAPI + Pydantic 让 `openapi.yaml` 与实现同源，前后端契约一致。
- 演示态零外部依赖，`uvicorn` 一条命令启动即可答辩。

### 负面
- 规则对**模板漂移**敏感：文本模板一旦改动，模式失配 → 解析召回下降（风险 R1）。
- 轻前端在交互复杂度上升后需要重构。

### 风险与缓解
| 风险 | 缓解 |
|---|---|
| R1 规则脆性 | 解析失败不静默跳过 → 产出 `UNPARSED_LINE`(P0)；规则带样本回归用例，模板变更即红灯 |
| R2 LLM 非确定性 | LLM 默认关闭；回归集禁用 LLM；结果仅作校验，冲突升级人工，并记录模型名/版本/入参摘要 |
| R3 归一化静默错误 | 金额用 Decimal；日期补全规则确定且可审计；对金额/日期/幂等键写变异定向用例 |
